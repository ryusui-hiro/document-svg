For AI agents

An AI assistant can learn how to use document-svg from this site without reading any code. Here is how to give it the tool, and what it should keep in mind.

Give your assistant the tool

Claude Code

Add the marketplace and install the plugin. You get commands to convert, write back, tidy up SVG, make PNG previews and check the setup.

/plugin marketplace add ryusui-hiro/document-svg
/plugin install document-svg@document-svg

Codex

Run the installer from a local checkout, then start a new task. The same skill becomes available.

./scripts/install-codex-plugin.sh

GitHub Copilot

Add the setup action to your Copilot setup steps and the coding agent can run the command while it works.

What an agent should know

  1. For ordinary files, use the simple convert step. The lower-level building blocks are for people drawing SVG from their own shapes.
  2. The file extension decides how a file is read. Check the format list before assuming a type is supported.
  3. Every page, slide or sheet becomes its own SVG, and one report covers the whole job.
  4. Finishing without an error does not mean perfect. Warnings mean a person should take a look.
  5. Use a new, empty output folder for every conversion.
  6. Use only the published interface. The internal readers can change between releases.
  7. Don't raise the safety limits to force a difficult file through. They protect the machine from oversized or hostile files.
  8. Turning an SVG back into Office or CAD keeps how it looks, not the original text flow, cells or formulas.
