How to read the table

  • "To SVG" means the file can be converted into SVG pages.
  • "From SVG" means SVG pages can be turned back into that kind of file.
  • A, B and C show how closely the result matches the original. A dash means that direction isn't supported.
  • Some formats are shown as a summary of their contents (for example page or item counts) rather than a full drawing. The description on each row says which.

How closely it matches

A
Faithful: drawn straight from the file's own contents. Nothing is guessed.
B
Traced: outlines are traced from pixels, so shapes are close but not exact.
C
Rebuilt: structure such as tables or connections is inferred from the drawing. Check the result.
