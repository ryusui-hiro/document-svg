面向 AI 智能体

AI 助手不必读代码，就能从这个网站了解用法。这里介绍怎么把这个工具交给 AI，以及它需要注意什么。

把工具交给 AI 助手

Claude Code

添加插件市场并安装插件后，就能使用转换、写回、整理 SVG、生成 PNG 预览、检查安装这五个命令。

/plugin marketplace add ryusui-hiro/document-svg
/plugin install document-svg@document-svg

Codex

在本地仓库中运行安装脚本，然后开始一个新任务，就能使用同样的技能。

./scripts/install-codex-plugin.sh

GitHub Copilot

在 Copilot 的准备步骤里加上安装用的 action，编码智能体在工作时就能使用命令。

智能体需要知道的几件事

  1. 普通文件转换用简单的转换入口即可；底层组件是给想用自己的图形生成 SVG 的人准备的。
  2. 文件按扩展名决定读取方式。先查支持格式列表，再判断是否支持。
  3. 每一页、每张幻灯片、每个工作表都会成为单独的 SVG，整个任务附带一份报告。
  4. 没有报错不代表完美。警告的意思是“需要人看一下”。
  5. 每次转换都用一个新的空文件夹作为输出位置。
  6. 只使用公开的接口；内部读取模块在不同版本之间可能变化。
  7. 不要为了让难处理的文件通过而调高安全上限。上限是为了保护机器免受超大或恶意文件的影响。
  8. 把 SVG 转回 Office 或 CAD 时，保留的是外观，而不是原来的文字排版、单元格或公式。
