AIエージェント向け

AIアシスタントは、コードを読まなくてもこのサイトから使い方をつかめます。AIにこの道具を渡す方法と、気をつけてほしいことをまとめました。

AIアシスタントに道具を渡す

Claude Code

マーケットプレイスを追加してプラグインを入れます。変換、書き戻し、SVGの整形、PNGのプレビュー作成、セットアップの確認、の5つのコマンドが使えるようになります。

/plugin marketplace add ryusui-hiro/document-svg
/plugin install document-svg@document-svg

Codex

リポジトリを手元に置いてインストーラーを実行し、新しいタスクを始めます。同じスキルが使えるようになります。

./scripts/install-codex-plugin.sh

GitHub Copilot

Copilot のセットアップ手順にセットアップ用のアクションを足すと、コーディングエージェントが作業中にコマンドを使えます。

エージェントに守ってほしいこと

  1. ふつうのファイル変換には、シンプルな変換の入口を使う。細かい部品は、自前の図形からSVGを作る人向け。
  2. ファイルの読み方は拡張子で決まる。対応していると決めつける前に、対応形式の一覧を見る。
  3. ページ、スライド、シートは1枚ずつ別のSVGになり、全体でレポートが1つ付く。
  4. エラーなく終わっても完璧とは限らない。警告は、人が確認すべきという合図。
  5. 変換のたびに、新しい空のフォルダを出力先にする。
  6. 公開されている入口だけを使う。内部の読み込み処理はリリースごとに変わる。
  7. 難しいファイルを通すために安全上の上限を上げない。上限は、巨大なファイルや悪意のあるファイルからマシンを守るためにある。
  8. SVGを Office や CAD に戻したとき残るのは見た目。元の文章の流れ、セル、数式は戻らない。
