## Format matrix

Conversions are classified into three fidelity tiers:
- **A (Deterministic)**: 1:1 syntax mapping, exact geometric projection, or lossless metadata round-tripping.
- **B (Vectorization)**: Raster image processing and contour tracing from pixel data.
- **C (Heuristic Reconstruction)**: Structural inference from unannotated 2D geometries (e.g., cell clustering for tables, topological parsing for graphs).
